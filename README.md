# WorkTimer v1.0.0

Erste Version eines kleinen JavaFX-Tools zur persönlichen Arbeitszeiterfassung.

Enthalten sind:

* Starten, Pausieren und Fortsetzen eines Arbeitstages
* Anzeige der aktuell geleisteten Arbeitszeit
* optionale Notizen pro Tag
* grafische Darstellung von vergangener und tatsächlich gearbeiteter Zeit
* Auswahl und Anzeige bereits gespeicherter Arbeitstage
* lokale Speicherung der Tagesdaten
* Excel-kompatibler CSV-Export aller gespeicherten Einträge

Die Anwendung speichert die Daten lokal und benötigt keinen Server oder Benutzeraccount.
